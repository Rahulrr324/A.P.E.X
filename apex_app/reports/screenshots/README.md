# Real-browser screenshots (T-31)

These PNGs are produced **only** by a run of `tests/e2e/t31-real-browser.spec.mjs` in a real
Chromium-family browser (Microsoft Edge, Google Chrome or Chromium resolved through
`src/ui/browser-binary.js`). Nothing in this directory is hand-made, generated by a model, or
captured from a simulated page.

- `t31_browser-run.json` — browser version, resolved executable, per-viewport results, overflow
  measurements, and each screenshot's byte size and pixel dimensions.
- `t31_<viewport>_<width>x<height>.png` — one screenshot per target viewport.

The development sandbox has no browser binary, so a local run writes nothing here and skips with
an explicit diagnostic. The GitHub-hosted runner has `/usr/bin/microsoft-edge`, so the CI job runs
the suite for real and uploads this directory as a workflow artifact. If this directory holds no
PNG, no browser check has been claimed.
