dependence sensitivity of the SAME rules at a true 0.90
  D0: independent 0.0070 | comonotone (all cells move together) 0.5761 | Frechet range [0, 0.5761]
  D3: cells independent 0.2306 | within-seed comonotone (a run either passes every task or none) 0.1912
      -> D3 spans 0.1912 .. 0.2306 : spread 0.0394, versus 0.5691 for D0
      -> counter-intuitive but correct: positive dependence LOWERS a k-of-n
         probability when k > n*q, so D3 is nearly dependence-robust while D0
         spans two orders of magnitude under the same assumption.
  D4: independent 0.1612 | perfectly correlated runs 0.5442
  D5: one test, no multiplicity, no cell structure: 0.5256

claim each rule supports
  D0  'every task, on every run'                 <- highest bar, worst power
  D3  'every task, on at least two of three runs'  <- matches a robustness claim
  D4  'the battery mean reaches 0.90 on every run'  <- allows one task to compensate
  D5  'the pooled rate exceeds 0.90'                <- a different, weaker claim

==============================================================================
6. effective sample size / experimental unit
==============================================================================
  trials per cell         120   -> measurement precision for ONE fixed checkpoint
  seeds (independent runs)  3   -> the only real replication of the training procedure
  tasks (fixed battery)     3   -> a fixed factor, not a random sample
  a claim about the METHOD therefore has n = 3, not 9 and not 1080
  Wilson 95% interval at 108/120 = (0.8333, 0.9419); half-width 0.0543
