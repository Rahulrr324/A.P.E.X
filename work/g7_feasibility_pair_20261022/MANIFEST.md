## 3. Build outputs (classification)

`work/g7_feasibility_pair_20261022/bin/{profiler_cli,run_baseline,aggregate}` are
reproducible build outputs, not evidence. They were already tracked in commit
`6d98b2e` and are **not deleted** (preserve-everything constraint). Their
canonical identity is their hashes; any audit can rebuild from `REPRODUCE.md` and
compare:

- `aggregate` `589d36b21cd6e825e7fb1adcda8800dc2edcb9aee70b99cd96f346d79360880d`
- `profiler_cli` `5b2925ddabb8d00e373dd124ccda58384b93e077a0615839efba2f1c2316654d`
- `run_baseline` `5cb55428fe7964ffcf6f09e18811006a083f814d4665f6328da28358cd641452`

This handoff commit adds no new executables or build trees. No build tree
(e.g. object files) exists in the package — the binaries were produced by direct
`g++` invocations (no CMake configure tree; `cmake` is unavailable in the
sandbox). Removing the three binaries from the branch would require a deletion
decision by the authority; it was deliberately not done here.
