## 1. Central invariants (restated, binding)

**I1 — One persistent system.** STARK Intelligence = Cognitive Controller + persistent local
state + locally-owned model weights. Local compute, the local model, tools, external APIs, cloud
execution and specialist models are *resources*. External resources may assist, teach, verify, or
provide temporary compute. They are never the persistent identity of STARK.

**I2 — Offline-first.** With internet, cloud and all external APIs disabled, STARK must still:
load identity/state/memory, plan tasks, use local resources, execute local tasks, verify results,
recover from failures, and learn/store verified outcomes. Every phase must have a stated offline
degradation story; a capability that cannot degrade offline is a resource, not part of STARK.

**I3 — Deterministic core.** The neural core is deterministic with fixed timestep and exact
checkpoint round-trip. All measurement and routing layers must preserve reproducibility of
records (see Phase 1 §F).

## 2. Mandatory corrections (binding)

### C1 — ProviderAdapter has EIGHT methods
`discover()`, `health()`, `estimate()`, `execute()`, `cancel()`, `usage()`, `capabilities()`,
`supported_schemas()`. All external adapters (cloud execution, APIs, specialist models) implement
this exact octet; `capabilities()` and `supported_schemas()` are the two methods that let the
router make decisions without execute calls. No adapter may be introduced with fewer methods.
(Not implemented in this gate; binding for the phase that first introduces adapters.)

### C2 — Formal privacy ordering
Domain `PrivacyLevel = { PUBLIC, INTERNAL, SENSITIVE, PRIVATE }` with total order
`PUBLIC < INTERNAL < SENSITIVE < PRIVATE`.

Formal comparison rule:
- Let `ord(x)` be the rank: `ord(PUBLIC)=0, ord(INTERNAL)=1, ord(SENSITIVE)=2, ord(PRIVATE)=3`.
- `x <= y  iff  ord(x) <= ord(y)` (total order, hence reflexive, antisymmetric, transitive).
- **Default rule (closure):** any datum with no explicit classification evaluates as `PRIVATE`
  (maximum). Unclassified == PRIVATE, not "lowest".
- **Flow rule:** a datum of level `L` may flow to a destination of level `M` only if `L <= M`
  (data may only move to equal-or-more-private contexts). Aggregation rule: the level of a
  derived/composite artifact is `max(ord)` over its inputs (join is max; there is no way to
  lower a level by combining or transforming data).

### C3 — External confidence is an untrusted signal
`SubtaskResponse` MAY carry a provider-supplied confidence value. STARK treats it as an
**untrusted, uncalibrated signal**: it is recorded, never used alone for decisions, and never
compared across providers. Decisions that need trust must use STARK's own `ResourceLedger`
statistics derived from *verified* task outcomes (executed locally or verified after external
execution). Formally: `trust(resource, task_class) := f(verified_ledger_stats)`, and
`provider_confidence ∈ SubtaskResponse` is at most a logged feature. No phase may promote
provider confidence into the trust computation without an explicit gate that proves calibration.

### C4 — "Architecture ready" vs "remaining blocking questions"
Resolved: an architecture is *ready* when (a) the invariant set (I1–I3) is closed, and (b) every
open question is **assigned to a named phase boundary** with the decision inputs identified.
Open questions are therefore not blockers to implementing already-specified phases; each becomes
an *implementation decision at its phase boundary*, decided by measurement, not debate:
- Tokenizer/sequence representation → boundary of the phase that first introduces the language
  interface.
- Long-term memory structure → boundary of the memory phase.
- Training data pipeline → boundary of the first training phase.
- Which precision/format wins for the Cognitive Core → the Phase-2 selection decision, consuming
  Phase-1 measurement outputs.

### C5 — ResourceRouter is pure
Signature (binding for the routing phase):

```
route(node: PlanNode, resource_snapshot: ResourceSnapshot, policy_snapshot: PolicySnapshot) -> RouteDecision
```

- Both snapshots are **immutable values** supplied by the caller. The router never reads a live
  registry, health probe, quota counter, clock, RNG, or filesystem.
- Freshness is the caller's responsibility: the caller refreshes snapshots before calling.
- Determinism guarantee: two calls with equal inputs produce equal `RouteDecision`s. This makes
  the router unit-testable with frozen snapshots and replayable in logs.
- Live state (health/quota/latency) enters only as fields *inside* the snapshots.

### C6 — STARK identity invariant (restated)
See I1. Additionally: the Cognitive Controller must never contain provider-specific logic;
provider knowledge lives in adapters + snapshots. External resources are optional and
degradeable. Any design that stores persistent STARK state outside local storage violates this gate.

### C7 — Offline invariant (restated)
See I2. Phase-specific instantiation: Phase 1 (this phase's successor, M0) runs entirely locally;
its only "external" surface is reading hardware/software facts from the local OS. No network
calls are permitted anywhere in Phase 1.

### C8 — Prohibition list (binding until individually re-gated)
Do not implement: provider marketplace; automatic paid billing; unrestricted autonomous external
access; persistent cloud memory; provider-specific logic in the Cognitive Controller;
unrestricted proactive behavior; giant-model pretraining; custom CUDA kernels; computer-control
implementation; Phase 6+ work. Each future phase must list which, if any, of these it lifts.
